# What
Access to a feature flag/toggle service that allows runtime control of application features. For e.g. LaunchDarkly, Split, Unleash, Azure App Configuration, AWS AppConfig, etc.
# Why
Enables safe feature rollouts, A/B testing, and the ability to quickly disable problematic features without redeployment, supporting continuous delivery practices and reducing deployment risk.
