# What
Pair programming is a collaborative software development technique where two developers work together at one workstation. One developer (the "driver") writes code while the other (the "navigator") reviews each line of code, thinks about the overall direction, and suggests improvements.
# Why
Pair programming offers significant benefits:
1. **Improved code quality** - Real-time code review catches issues immediately
2. **Knowledge sharing** - Both developers learn from each other and share domain knowledge
3. **Reduced bugs** - Two sets of eyes catch more mistakes than one
4. **Better design decisions** - Collaborative thinking leads to better architectural choices
5. **Faster onboarding** - New team members learn faster when paired with experienced developers
6. **Reduced silos** - Multiple people understand each part of the codebase
