# What
Living documentation is documentation that evolves with the codebase and stays up-to-date automatically or through integrated processes. This includes executable specifications, auto-generated API docs, inline code comments, and documentation that's maintained as part of the development workflow.

# Why
Living documentation provides:
1. **Always current** - Documentation stays synchronized with the actual codebase
2. **Reduced maintenance** - Automated generation reduces manual documentation overhead
3. **Developer adoption** - Documentation integrated into development workflow is more likely to be maintained
4. **Faster onboarding** - New team members have access to current, accurate information
5. **Better decisions** - Up-to-date documentation enables better architectural and design decisions
6. **Knowledge preservation** - Important information is captured and maintained over time
