# What
Infrastructure as Code (IaC) is the practice of managing and provisioning infrastructure through machine-readable definition files, rather than physical hardware configuration or interactive configuration tools. Infrastructure is treated the same way as application code.
# Why
Infrastructure as Code provides crucial benefits:
1. **Consistency** - Infrastructure environments are identical and reproducible
2. **Version control** - Infrastructure changes are tracked, reviewed, and can be rolled back
3. **Automation** - Infrastructure provisioning and updates can be fully automated
4. **Documentation** - Infrastructure configuration serves as living documentation
5. **Cost efficiency** - Resources can be created and destroyed on demand
6. **Compliance** - Infrastructure configurations can be audited and enforced automatically
